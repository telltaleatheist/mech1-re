# The UI words the importer takes from the player's exes (docs/phase2/PLAN.md
# section 7), into story/words.json. One per line, as pieces.txt: id, exe,
# SEG:OFF (BTECH in its unpacked image, loaded at 0810), and `z` for a string
# read up to and including its NUL, or a byte count for a block kept whole.
# tools/import/make_import_table.py adds them to import_table.cpp with a keyed
# hash (ImportTable.h). Ids and places only: never the words.
#
# A line `captions <screen>` stands for the text of each of that screen's
# captions in src/Ui/ui_pieces.txt, as `<caption id>.text` right after the
# caption's head, NUL-ended. A caption whose text is a fixed-width row the code
# fills in is listed here with its byte count instead, and the line skips it.
